# קפה פנוי

איזה בית קפה או עגלת קפה פנויים עכשיו לידך, מה עמוס, ומתי הכי שקט. חינמי לגמרי: בלי מפתחות API בתשלום.

## איך זה עובד

| מה | מאיפה |
|---|---|
| בתי קפה ועגלות | OpenStreetMap — קובץ `public/data/places.json` שמתעדכן כל שבוע אוטומטית (GitHub Action), ועגלות שמשתמשים מוסיפים |
| שעות פתיחה | OpenStreetMap; כשאין, שעות משוערות שמסומנות ככאלה |
| **עומס עכשיו** | דיווחי משתמשים מ-45 הדקות האחרונות ("אין תור / קצת תור / תור ארוך") |
| **מתי פנוי** | דיווחים מהעבר לפי יום ושעה למקום הזה; עד שיש מספיק — הערכה לפי דפוסי יום ושעה בישראל |
| בדיקה כפולה | קישור לגוגל מפות, שמראה שם "עומס חי" כשיש לו |

כל סטטוס מראה מאיפה הוא בא: דיווח חי, דיווחים קודמים, או הערכה.

## הרצה

```bash
npm install
npm run dev
```

בלי הגדרות נוספות האפליקציה עובדת במצב מקומי: הדיווחים נשמרים רק בדפדפן.

## חיבור שרת חינמי (Supabase) — כדי שדיווחים יגיעו לכולם

1. פותחים פרויקט חינמי ב-[supabase.com](https://supabase.com).
2. ב-SQL Editor מריצים את `supabase/schema.sql`.
3. מעתיקים מ-Project Settings → API את ה-URL ואת ה-anon/publishable key.
4. מגדירים משתני סביבה (מקומית ב-`.env.local`, ובנטליפיי ב-Site settings → Environment variables):

```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=...
```

ה-anon key ציבורי מטבעו. הטבלאות נעולות לגמרי, וכל קריאה וכתיבה עוברות דרך פונקציות שבודקות קלט ומגבילות קצב לפי מכשיר.

## פריסה

Netlify: `npm run build`, תיקיית `dist`.

רשימת המקומות נבנית ב-GitHub Actions (`Update places from OpenStreetMap`) — כל יום שני, או ידנית מלשונית Actions.
